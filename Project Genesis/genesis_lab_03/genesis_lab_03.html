중요한 한계
모델이 연산 자체를 발명한 것은 아니야. 사람이 제공한 연산 문법(+, −, ×) 안에서 식을 생성하는 기호적 특징 탐색이야. 새로운 데이터를 볼 때마다 정답 라벨이 제공되는 지도학습이고, 이 실험만으로 자율적인 과학적 직관이 구현됐다고 할 수는 없어. 왼쪽 절반만 관측하면 식을 식별하지 못할 수도 있어.
공정성 메모: 세 모델 모두 동일한 관측 데이터에서 학습한다. 훈련/검증 자료는 나눠 사용하고, 별도로 생성한 시험점 900개는 모델 선택에 쓰지 않는다. 새 좌표 모델은 최대 식 복잡도 7의 연산식 중 검증 오류와 복잡도 패널티가 낮은 식을 택한다. 사용자가 시험 정확도를 보고 환경이나 시드를 반복 선택할 경우 그것은 탐색적 실험이며, 논문 수준의 독립 최종 검증은 별도 데이터로 다시 해야 한다.
