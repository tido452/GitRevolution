# PROJECT GENESIS — Experiment 04

**목표:** 관측된 2차원 규칙을 설명하는 새로운 복합 특징 `z = f(x, y)`를 주어진 기본 연산으로 탐색한다. '천재적인 직관'이나 AGI를 입증한 결과가 아니라 기능주의적 직관 가설을 검증하기 위한 작은 실험이다.

## 실행

1. `genesis_lab_04.html` 파일을 **Safari 또는 Chrome**에서 연다. 네트워크, Python, Node, API 키가 필요 없다.
2. 기본 환경 `주기적 줄무늬`에서 **진화 시작**을 클릭한다. 진행되는 80세대의 최고 표현식을 관찰한다.
3. **숨겨진 정답**, **선형**, **기억**, **GENESIS 04** 탭으로 분류 지도를 비교한다.
4. **개념 저장**을 누르고 다른 세계로 바꾼 다음 진화한다. 저장된 표현은 후보 초기 집합으로 사용되며 새로운 환경의 정답을 보장하지 않는다.
5. **기울어진 물결**로 바꿔 실패 가능성도 살펴본다.
6. `결과 CSV`로 진행 기록을 저장한다.

## 구현 원리

- 인공신경망 기반 언어모델이 아니다. **기호 회귀 / 유전적 프로그래밍** 계열.
- 한 개체는 수식 구문 트리. 미리 허용된 원시연산은 변수 `x, y`, 상수 집합, `+`, `-`, `×`, `sin`, `cos`, 제곱, 절댓값, 부호 반전이다. **새 원시연산을 발명하지는 못한다.**
- 매 세대 160개 후보에 대해 지도학습 훈련 정확도와 표현식 노드 수를 점수화한다.
- 우수 후보를 보존하고, 하위 트리의 교차·변이를 통해 새로운 복합 표현식을 만든다. 최대 19노드, 80세대.
- 각 표현식의 최적 임계값과 부호 방향은 **훈련 데이터에서만** 결정한다.
- 75%의 관측으로 유전 탐색을 진행하고, 25%를 모델 선택에 사용한다. 검증 데이터의 **관측 라벨**(정답 없는 잠재 truth가 아님)을 사용한다. 별도로 생성한 1,000개 시험점은 알고리즘 평가에만 사용한다.
- 선형 로지스틱 회귀와 5-최근접이웃(k-NN)도 **동일한 전체 관측 예산**을 활용한다. 이 대조군은 관측 전체를 학습하며, GENESIS만 훈련/검증을 나눈다.
- 모든 모델은 관측마다 **정답 라벨을 받는다.** 외부 환경의 법칙을 무지도 학습하거나 새 수학 연산을 발명한 것은 아니다.

## 재현 가능한 평가

Node.js를 쓸 수 있다면 폴더에서 아래를 실행한다.

```bash
node benchmark_genesis04.js '' 8 80 120 160
```

6개 고정 과제 × 8개 시드(178, 309, …) × 120개 라벨 관측(훈련 90 / 검증 30) × 진화 80세대 × 시험점 1,000개. 분류 정확도 8회 평균(%). **주기적 줄무늬는 GENESIS 03의 물결 과제와 동일한 `sin(3.5πx) > 0` 정의**를 사용한다. 현재 구현의 실험 결과:

| 환경 | 선형 회귀 | 5-NN 기억 | GENESIS 04 |
|---|---:|---:|---:|
| XOR | 51.5 | 94.4 | 99.5 |
| 원형 경계 | 64.7 | 94.2 | 98.1 |
| 포물선 | 89.1 | 95.8 | 97.3 |
| 주기적 줄무늬 | 50.2 | 75.9 | 95.5 |
| 기울어진 물결 | 57.8 | 92.5 | 94.9 |
| 대각선 | 97.1 | 96.3 | 98.7 |

**주의:** 모든 과제는 실험자가 설계했다. 낮은 계산량, 편향 없는 대규모 세계, 자율적 관찰·실험, 초지능의 증거가 아니다. 연산 집합과 상수 범위가 문제에 따라 유리할 수 있으며, 모델 간 연산 예산과 표현력이 같지 않다. 실험자가 표시된 시험 점수를 보고 반복적으로 설계를 조정하면 테스트 과적합이 생길 수 있다. 논문용 주장을 위해서는 잠금된 추가 최종 시험 시드와 더 강한 비교 모델을 준비해야 한다.
